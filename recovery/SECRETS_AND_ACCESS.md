# 凭据与授权边界

- **绝不提交** API 密钥、访问令牌、Cookie、SSH 私钥、密码、.env、浏览器导出、macOS 钥匙串或未脱敏日志。
- 仓库只保存：变量名称示例、凭据存放位置类别、重新授权入口与验证步骤。
- 推荐存放位置：密码管理器、macOS 钥匙串或权限收紧的本机文件；应由用户控制访问。
- 恢复时，先检查该安全位置；找不到或失效时，去服务商官方页面重新授权或轮换凭据。
- 重新授权后，用最小权限和只读健康检查验证，再恢复写入、通知或交易类工作流。
- 如果怀疑密钥泄露，立即在服务商后台撤销 / 轮换，随后更新本地安全存放处；不要通过 Git 历史“删除”来解决泄露。
